## Team Consensus

All 5 roles approved the brief with conditions. Key agreements:

1. **Only Phases 1-2 before investor demo** (Conductor). Phases 3-5 defer to post-demo sprint.
2. **Import paths in the brief are wrong** (DevOps + Developer). Both documented correct osbot-utils 3.72.0 paths.
3. **Co-migrate `Audit_Trail` with `Schema__Audit_Entry`** in Phase 1 (Architect C6). Deleting `compute_hash()` from the entry breaks the trail otherwise.
4. **Split shared types by domain boundary** (Architect C3). Not all in `ec2/schemas/EC2__Types.py`.
5. **Clear audit trail at v0.1.x** for hash migration (DevOps + AppSec). No production data rooms exist yet.
6. **`SSH__Port_Forward` stays plain class** (Developer). `subprocess.Popen` conflicts with Type_Safe.
7. **`EC2_Provider` stays `ABC`** (Architect). Only concrete implementations get Type_Safe.
8. **`enforce_limits` should default to `True`** (AppSec). Budget controls are a hard requirement.
9. **Keep service methods returning `dict`** in Phase 3 (Developer). Change return types separately if ever.
10. **Add API contract tests before Phase 3** (Architect C5).

**Goal:** Fix the two CRITICAL `__init__` bypasses and migrate audit entry + trail together.

- Declare `security_groups : list` and `tags : dict` as class-level attributes (raw types for now — typed collections come in Phase 2)

#### Step 1.2: `Schema__Twin__EC2__Security_Group` (config + state)
- Remove `__init__` from both config and state classes
- Declare `ingress_rules : list`, `egress_rules : list`, `associated_instances : list` as class attributes
- **Test gate:** all 138 pass
- Commit

#### Step 1.3: `EC2_Audit_Entry` → `Schema__Audit_Entry(Type_Safe)`
- Add `Type_Safe` inheritance
- Remove `__init__` — declare all fields as class-level annotations
- Delete `json()` method (Type_Safe provides it)
- Delete `compute_hash()` (moves to Audit_Trail)
- Keep `timestamp` as `str` for now (not `Timestamp_Now` yet — avoids hash chain breakage)
- **Test gate:** update `test__EC2_Schemas.py` audit entry tests, all pass
- Commit

#### Step 1.4: `Audit_Trail` → `Audit_Trail(Type_Safe)`
- Add `Type_Safe` inheritance
- Remove `__init__` — declare `entries : list` and `last_hash : str` as class attributes
- Move hash computation here using `Cache__Hash__Generator`
- Start new hash chain epoch (prev_hash = '' for first entry)
- **Test gate:** update `test__Audit_Trail.py`, all pass
- Commit

#### Step 1.5: Flip `enforce_limits` default to `True` in `EC2_Budget_Config`
- Change `enforce_limits : bool = False` → `enforce_limits : bool = True`
- Update any tests that rely on the default being False

- Commit
