## Summary

Fixed the admin UI web component architecture so child components survive the shell's rendering lifecycle. Verified all API paths between the JS client and FastAPI routes.

## Admin Shell Bug

**Problem:** `AdminShell.connectedCallback()` used `this.innerHTML = ...` which destroyed all child elements (`<ec2-instances>`, `<system-info>`). The `<slot>` tag in the template was meaningless without Shadow DOM.

**Fix:** Capture `childNodes` before innerHTML, then re-append them into the `.panel` div after rendering.

**Pattern to follow:** Any web component that wraps child content in light DOM must preserve children before setting innerHTML. Alternative: use Shadow DOM with `attachShadow({mode: 'open'})` and real `<slot>` elements.
