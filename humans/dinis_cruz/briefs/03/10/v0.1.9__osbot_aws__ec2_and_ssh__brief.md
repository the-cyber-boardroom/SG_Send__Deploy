## Class Map

```
osbot_aws
└── aws/ec2/
    ├── EC2                        ← raw AWS API calls (boto3 wrapper)
    └── EC2_Instance               ← single-instance lifecycle + SSH bootstrap

osbot_utils
└── helpers/ssh/
    ├── SSH                        ← facade: one object, access everything below
    ├── SSH__Execute               ← subprocess ssh binary wrapper; arg builder

    └── SCP                        ← file copy to/from host (extends SSH__Execute)
```

## 1. EC2 — Raw AWS API

`EC2` is a `Type_Safe` wrapper over `boto3.client('ec2')`. Every method maps directly to an AWS API call.

### Instance lifecycle

```python
from osbot_aws.aws.ec2.EC2 import EC2

ec2 = EC2()

# Create (returns instance_id str)
instance_id = ec2.instance_create(
    image_id          = 'ami-046c2381f11878233',
    instance_type     = 't3.small',
    key_name          = 'my-key',
    security_group_id = 'sg-xxxxxxxx',
    spot_instance     = True,                    # Spot via InstanceMarketOptions
    name              = 'my-instance',
    tags              = {'Purpose': 'qa-llm'}
)

ec2.instance_details(instance_id)    # → dict: public_ip, state, instance_type, …
ec2.instance_start(instance_id)
ec2.instance_stop(instance_id)
ec2.instance_terminate(instance_id)

# Waiters (blocks until condition met; delay=1s, max_attempts=600 by default)
ec2.wait_for_instance_running(instance_id)
ec2.wait_for_instance_stopped(instance_id)
ec2.wait_for_instance_terminated(instance_id)
```

### Key pairs

```python
# Creates key pair in AWS, writes .pem to disk, sets chmod 400
result = ec2.key_pair_create_to_file(
    key_name      = 'sgraph-qa-abc123',
    target_folder = '/tmp'          # defaults to temp_folder() if omitted
)
# result = { 'path_key_pair': '/tmp/sgraph-qa-abc123.pem',
#             'key_pair_id':  'key-xxxxxxxxxxxxxxxxx',
#             'key_pair':     { ... raw AWS response ... } }

ec2.key_pair_delete(key_pair_id='key-xxx')    # by ID
ec2.key_pair_delete(key_pair_name='my-key')   # by name
ec2.key_pair_exists(key_pair_name='my-key')   # → bool
ec2.key_pairs(index_by='KeyName')             # → dict of all key pairs
```

### Security groups

```python
ec2.security_group_create('sg-name', 'description', vpc_id='vpc-xxx')
# returns status_ok/status_warning with data.security_group_id

ec2.security_group_authorize_ingress(
    security_group_id = 'sg-xxx',
    port              = 22,
    cidr_ip           = '1.2.3.4/32',    # scope to runner IP
    ip_protocol       = 'tcp'
)
# revoke is not on EC2 directly — use client().revoke_security_group_ingress(...)

ec2.security_group_delete(security_group_id='sg-xxx')
ec2.security_group(security_group_name='my-sg')   # → dict or None
```

### AMIs

```python
ec2.ami('ami-xxxxxxxx')                    # → single AMI dict
ec2.amis(name='sgraph-qa-llm-*')          # → list, supports wildcards via filter
ec2.create_image(
    instance_id = 'i-xxx',
    name        = 'sgraph-qa-llm-gemma3-4b-v1',
    no_reboot   = True
)                                          # → ami_id str
```

### index_by / group_by decorators

Most list methods support these keyword args (via `@index_by @group_by` decorators):

```python
ec2.instances_details()                            # → {instance_id: details_dict}
ec2.security_groups(index_by='GroupId')            # → {sg_id: sg_dict}
ec2.security_groups(group_by='GroupName')          # → {name: [sg_dict, …]}
ec2.key_pairs(index_by='KeyName')                  # → {key_name: key_dict}
ec2.amis(index_by='ImageId')                       # → {ami_id: ami_dict}
```

## 2. EC2_Instance — Lifecycle + SSH Bootstrap

`EC2_Instance` wraps `EC2` with instance-level state. It is what `Mitmproxy__Create__EC2_Instance` uses as its primary object.

```python
from osbot_aws.aws.ec2.EC2_Instance import EC2_Instance

# Two construction patterns:

# Pattern A: create a new instance
ec2_instance = EC2_Instance()
ec2_instance.create_kwargs = dict(
    image_id          = 'ami-046c2381f11878233',
    instance_type     = 't3.small',
    key_name          = 'my-key',
    security_group_id = 'sg-xxx',
    spot_instance     = True,
    tags              = {'Type': 'EC2_Instance'}
)
instance_id = ec2_instance.create(instance_name='my-instance')

# Pattern B: wrap an existing instance
ec2_instance = EC2_Instance(instance_id='i-xxxxxxxxxxxxxxxxx')
```

### Key methods

```python
ec2_instance.create()               # launches instance, stores instance_id, returns id
ec2_instance.delete()               # terminates
ec2_instance.exists()               # → bool
ec2_instance.info()                 # → details dict (public_ip, state, …)
ec2_instance.ip_address()           # → str public IP
ec2_instance.state()                # → { 'Code': 16, 'Name': 'running' }
ec2_instance.tags()                 # → list of {'Key':…, 'Value':…}
ec2_instance.start()
ec2_instance.stop()                 # calls instance_terminate (!) — check source
```

### SSH bootstrap

```python
# wait_for_ssh polls is_port_open(ip, 22) — this IS the readiness signal
ec2_instance.wait_for_ssh()

# Returns SSH object (configured via env vars internally)
ssh = ec2_instance.ssh(
    ssh_key_file = '/tmp/my-key.pem',
    ssh_key_user = 'ubuntu'           # 'ec2-user' for Amazon Linux
)
```

> **Note:** `EC2_Instance.ssh()` sets `SSH__HOST`, `SSH__KEY_FILE`, `SSH__USER` as environment
> variables then calls `ssh.ssh_execute().setup()`. This is why `Mitmproxy__Create__EC2_Instance`
> gets SSH key info from env vars.

### Context manager usage (from Mitmproxy)

`EC2_Instance` supports `with` — but only via `Temp_EC2_Instance`. The Mitmproxy code uses
`with self.ec2_instance(instance_id) as _:` which works because `EC2_Instance` has `__enter__`/`__exit__`
(inherited from `Kwargs_To_Self`). The SSH object returned also works as a context manager.

```python
with EC2_Instance(instance_id='i-xxx') as ec2_inst:
    ec2_inst.wait_for_ssh()
    with ec2_inst.ssh(key_file, 'ubuntu') as ssh:
        result = ssh.exec('hostname')
```

## 3. SSH — The Facade

`SSH` is what `EC2_Instance.ssh()` returns. It composes all SSH capabilities under one object.

```python
from osbot_utils.helpers.ssh.SSH import SSH

# All sub-objects are @cache_on_self — created once, reused
ssh.exec(command)         # → stdout str  (shortcut for ssh_execute().execute_command__return_stdout())
ssh.ssh_execute()         # → SSH__Execute
ssh.ssh_linux()           # → SSH__Linux
ssh.ssh_linux_amazon()    # → SSH__Linux__Amazon  (Amazon Linux variant)
ssh.ssh_python()          # → SSH__Python
ssh.scp()                 # → SCP
```

### Setup (standalone, no EC2)

```python
import os
from osbot_utils.helpers.ssh.SSH__Execute import (
    ENV_VAR__SSH__HOST, ENV_VAR__SSH__KEY_FILE, ENV_VAR__SSH__USER
)

os.environ[ENV_VAR__SSH__HOST    ] = '1.2.3.4'
os.environ[ENV_VAR__SSH__KEY_FILE] = '/tmp/my-key.pem'
os.environ[ENV_VAR__SSH__USER    ] = 'ubuntu'

ssh = SSH()
ssh.setup()   # reads env vars into ssh_execute()
```

## 4. SSH__Execute — Subprocess SSH Wrapper

The foundation. All SSH operations go through here. Uses `subprocess.run` (blocking).

### Configuration fields

```python
ssh_execute.ssh_host          : str        # target IP / hostname
ssh_execute.ssh_port          : int = 22
ssh_execute.ssh_key_file      : str        # path to .pem
ssh_execute.ssh_key_user      : str        # ubuntu / ec2-user / root
ssh_execute.strict_host_check : bool = False   # -o StrictHostKeyChecking=no
ssh_execute.print_after_exec  : bool = False   # pretty-print every result
```

### Execution methods

```python
se = ssh.ssh_execute()

se.execute_command(command)
# → { 'stdout': str, 'stderr': str, 'status': str, 'command': str, 'duration': dict }

se.exec(command)                        # → stdout str (strips whitespace)
se.execute_command__return_stdout(cmd)  # same as exec()
se.execute_command__return_stderr(cmd)
se.execute_command__return_dict(cmd)    # parses tabular stdout → list of dicts
se.execute_command__return_list(cmd)    # splits stdout by lines → list

# Debug printing
se.exec__print(command)                 # exec + pretty-print result
se.print_after_exec = True              # print every subsequent command
```

### SSH arg builder

```python
se.execute_ssh_args()
# builds: ['-p', '22', '-o', 'StrictHostKeyChecking=no', '-i', '/tmp/key.pem']
# used internally by execute_command() AND by the port-forward extension
```

### The port-forward gap (TODO in SSH__Linux)

`SSH__Execute` has no port-forward method. The TODO comment is in `SSH__Linux`:

```python
# if port_forward:      # todo: add support for port forward (this will need async execution)
#     local_port  = port_forward.get('local_port' )
#     remote_ip   = port_forward.get('remote_ip'  )
#     remote_port = port_forward.get('remote_port')
```

**The fix** (8 lines, `subprocess.Popen` instead of `subprocess.run`):

```python
import subprocess

def start_port_forward(self, local_port: int, remote_port: int,
                       remote_host: str = '127.0.0.1'):
    """Start SSH tunnel in background. Caller must call .terminate()."""
    ssh_args  = self.execute_ssh_args()
    ssh_args += ['-N']
    ssh_args += ['-L', f'{local_port}:{remote_host}:{remote_port}']
    ssh_args += [self.execute_command_target_host()]
    return subprocess.Popen(['ssh'] + ssh_args)

# Usage:
tunnel = ssh.ssh_execute().start_port_forward(11435, 11434)
# … HTTP calls to localhost:11435 routed to remote:11434 …
tunnel.terminate()
```

## 6. SCP — File Transfer

`SCP` extends `SSH__Execute` directly (not via `SSH__Linux`). Access via `ssh.scp()`.

```python
scp = ssh.scp()

# Upload
scp.copy_file_to_host(
    local_file = '/tmp/config.json',
    host_file  = '.'           # '.' = home dir; or explicit remote path
)

# Download
scp.copy_file_from_host(
    host_file  = 'results.json',
    local_file = '/tmp/results.json'
)

# Upload entire folder as zip, unzip on host
scp.copy_folder_as_zip_to_host(
    local_folder   = '/tmp/my_scripts',
    unzip_to_folder = '/home/ubuntu/scripts'
)
# internally: zips → scp → ssh unzip → rm zip
```

> **Port flag note:** `SCP` internally converts `-p` to `-P` (SSH and SCP use different flags for port — see comment in source: `"this hack is to handle the fact that ssh and scp use different flags for the port!! WTF!!"`)

## 7. SSH__Python — Remote Python Execution

```python
py = ssh.ssh_python()

py.python_version()                          # → 'Python 3.10.x'
py.pip_version()
py.pip_list()                                # → {package_name: dict}
py.pip_install('requests')
py.install_python3()                         # apt-get install python3

# Execute arbitrary Python code string
py.execute_python__code('import sys; print(sys.version)')
py.execute_python__code__return_stdout('print(42)')   # → '42'

# Execute a local Python function remotely
def get_hostname():
    import socket
    return socket.gethostname()

py.execute_python__function(get_hostname)
py.execute_python__function__return_stdout(get_hostname)  # → hostname str
```

> `execute_python__function` serialises the function source code via `function_source_code()`,
> appends `result = fn(); print(result)`, and runs it via `python3 -c "..."` over SSH.

## 8. The Mitmproxy Pattern — Full Reference

`Mitmproxy__Create__EC2_Instance` is the canonical real-world example. Key patterns to extract:

### Configuration via env vars

```python
security_group_id = get_env('EC2_TESTS__SECURITY_GROUP_ID')
ssh_key_name      = get_env('EC2_TESTS__PATH_SSH_KEY_FILE_NAME')
ssh_key_file      = get_env('EC2_TESTS__PATH_SSH_KEY_FILE', '')
ssh_key_user      = get_env('EC2_TESTS__PATH_SSH_KEY_USER')
```

### Instance creation

```python
ec2_instance = EC2_Instance()
ec2_instance.create_kwargs = dict(
    image_id          = DEFAULT__AWS__UBUNTU_LINUX_AMI,
    key_name          = ssh_key_name,
    security_group_id = security_group_id,
    instance_type     = 't3.small',
    spot_instance     = True
)
instance_id = ec2_instance.create(instance_name=instance_name)
```

### SSH with readiness check

```python
with self.ec2_instance(instance_id) as _:
    _.wait_for_ssh()
    return _.ssh(ssh_key_file=ssh_key_file, ssh_key_user=ssh_key_user)
```

### Full provisioning flow

```python
with self.ec2_instance_ssh(instance_id) as _:
    _.ssh_execute().print_after_exec = True     # print every command result

    # Remote commands
    _.exec('sudo apt-get update')
    _.exec('sudo apt install -y python3-pip')
    _.exec('sudo apt install mitmproxy -y')
    _.exec('mitmproxy --version')

    # File uploads via SCP
    _.scp().copy_file_to_host(local_file, '.')

    # Remote command after upload
    _.exec('tar -xzf mitmproxy-certs-backup.tar.gz')

    # systemd service management
    _.exec('sudo systemctl daemon-reload')
    _.exec('sudo systemctl enable mitmproxy')
    _.exec('sudo systemctl start mitmproxy')
    _.exec('sudo systemctl status mitmproxy')
```

### wait_for_ssh with boot detection

The Mitmproxy code has a more thorough wait (not just port polling):

```python
def wait_for_ssh(self, instance_id, max_tries=20, delay=1):
    with self.ec2_instance_ssh(instance_id=instance_id) as _:
        for i in range(0, max_tries):
            response = _.exec('pwd')
            if "System is booting up." in response.get('stderr'):
                wait_for(delay)         # still booting, wait
            else:
                if response.get('stdout') == '/home/ubuntu\n':
                    return              # fully up
                raise Exception(...)   # unexpected state
```

> `EC2_Instance.wait_for_ssh()` only polls `is_port_open`. The Mitmproxy pattern additionally
> executes `pwd` and checks stderr for the Ubuntu boot message — more reliable for provisioning.

## 9. Ephemeral Key + Security Group Pattern

Used in the EC2 LLM architecture:

```python
run_id = random_uuid_short()

# 1. Ephemeral key pair
result       = ec2.key_pair_create_to_file(key_name=f'sgraph-qa-{run_id}', target_folder='/tmp')
path_key_pair = result['path_key_pair']
key_pair_id   = result['key_pair_id']

# 2. Scope SG rule to runner IP only
ec2.security_group_authorize_ingress(SG_ID, port=22, cidr_ip=f'{runner_ip}/32')

try:
    # 3. Launch
    ec2_instance = EC2_Instance()
    ec2_instance.create_kwargs = dict(
        image_id=AMI_ID, instance_type='c7g.xlarge',
        key_name=f'sgraph-qa-{run_id}', security_group_id=SG_ID,
        spot_instance=True, tags={'RunId': run_id}
    )
    ec2_instance.create()

    # 4. Wait + connect
    ec2_instance.wait_for_ssh()
    with ec2_instance.ssh(path_key_pair, 'ubuntu') as ssh:
        tunnel = ssh.ssh_execute().start_port_forward(11435, 11434)
        try:
            # 5. Use Ollama via tunnel
            results = run_checks(ollama_url='http://localhost:11435')
        finally:
            tunnel.terminate()

finally:
    # Always clean up — even on exception
    ec2_instance.delete()
    ec2.key_pair_delete(key_pair_id=key_pair_id)
    ec2.client().revoke_security_group_ingress(
        GroupId=SG_ID, IpProtocol='tcp', FromPort=22, ToPort=22,
        CidrIp=f'{runner_ip}/32'
    )
    os.unlink(path_key_pair)
```

## 10. Quick Reference

| Need | Use |
|---|---|
| Launch instance | `EC2.instance_create(image_id, key_name, sg_id, spot_instance=True)` |
| Wait for boot | `EC2_Instance.wait_for_ssh()` (port 22 poll) |
| Get SSH object | `EC2_Instance.ssh(key_file, user)` |
| Run shell command | `ssh.exec(cmd)` → stdout str |
| Run with full result | `ssh.ssh_execute().execute_command(cmd)` → dict |
| Linux helpers | `ssh.ssh_linux().ls()`, `.cat()`, `.which()`, `.running_processes()` |
| Upload file | `ssh.scp().copy_file_to_host(local, remote)` |
| Download file | `ssh.scp().copy_file_from_host(remote, local)` |
| Upload folder | `ssh.scp().copy_folder_as_zip_to_host(folder, dest)` |
| Run Python remotely | `ssh.ssh_python().execute_python__function(fn)` |
| Port forward (needs adding) | `ssh.ssh_execute().start_port_forward(local, remote)` → Popen |
| Ephemeral key | `EC2.key_pair_create_to_file(name, folder)` → path + id |
| Bake AMI | `EC2.create_image(instance_id, name)` → ami_id |
| Print all SSH output | `ssh.ssh_execute().print_after_exec = True` |
