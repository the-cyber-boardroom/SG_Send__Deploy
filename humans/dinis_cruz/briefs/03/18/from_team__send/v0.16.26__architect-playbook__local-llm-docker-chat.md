## 1. Build Order

This is the sequence that gives you a working, testable system at each step. Do not skip steps or reorder — each step depends on the previous one passing tests.

| Phase | What | Tests Before Moving On | Time Est. |
|---|---|---|---|
| **P1** | Named types + schemas | `test_Schema__Chat__Message`, `test_Schema__Chat__Session` | 30 min |
| **P2** | `Service__Chat__Sessions` + `Storage_FS__Memory` | `test_Service__Chat__Sessions` (full CRUD) | 45 min |
| **P3** | `Service__Ollama__Proxy` (mock first, real second) | `test_Service__Ollama__Proxy` | 30 min |
| **P4** | Route classes + `Fast_API__Local_LLM` | `test_Routes__Sessions`, `test_Routes__Models` | 45 min |
| **P5** | Streaming route (`Routes__Chat`) | `test_Routes__Chat` (the novel pattern) | 45 min |
| **P6** | Docker + static UI | Manual: `docker compose up`, open browser, chat works | 30 min |

**Total estimate: ~4 hours** for backend + Docker. Frontend Web Components are unchanged from the original brief and can proceed in parallel.

        with Schema__Chat__Message() as _:
            assert type(_)         is Schema__Chat__Message
            assert type(_.role)    is Enum__LLM__Role
            assert type(_.content) is not str                # Should be Safe_Str__LLM__Prompt

## 3. Phase 2 — Session Service

### Step 2.1: Create Service__Chat__Sessions

Copy from §5.1 of the contract document. Key points:

- Constructor auto-creates `Storage_FS__Memory` if no storage provided
- All methods use `@type_safe` decorator
- `json_dumps` / `json_loads` from `osbot_utils.utils.Json` — NOT raw `json` module
- Returns `None` for not-found — no exceptions (Type_Safe convention)

### Step 2.2: Write service tests

```python
# tests/unit/service/test_Service__Chat__Sessions.py
from unittest                                                            import TestCase
from sg_send_deploy_local_llm.schemas.Schema__Chat__Session              import Schema__Chat__Session
from sg_send_deploy_local_llm.schemas.Schema__Chat__Message              import Schema__Chat__Message
from sg_send_deploy_local_llm.service.Service__Chat__Sessions            import Service__Chat__Sessions

class test_Service__Chat__Sessions(TestCase):

    @classmethod
    def setUpClass(cls):                                     # ONE TIME — expensive setup
        cls.service = Service__Chat__Sessions()              # in-memory storage, ~0ms

    def _create_test_session(self):                          # Helper — create a session with messages
        session = Schema__Chat__Session(model='gemma3:4b', title='Test')
        session.messages.append(Schema__Chat__Message(role='user', content='hello'))
        return self.service.create(session)

    def test__create_and_get(self):                           # Create → get round-trip
        created  = self._create_test_session()
        loaded   = self.service.get(created.id)
        assert loaded is not None
        assert str(loaded.id)    == str(created.id)
        assert str(loaded.title) == 'Test'
        assert len(loaded.messages) == 1

    def test__get__not_found(self):                           # Get non-existent session
        from sg_send_deploy_local_llm.schemas.types.Chat__Session_Id import Chat__Session_Id
        result = self.service.get(Chat__Session_Id('00000000'))
        assert result is None

    def test__update(self):                                   # Update adds message
        created = self._create_test_session()
        created.messages.append(Schema__Chat__Message(role='assistant', content='hi'))
        self.service.update(created)
        loaded = self.service.get(created.id)
        assert len(loaded.messages) == 2

    def test__delete(self):                                   # Delete removes session
        created = self._create_test_session()
        assert self.service.delete(created.id) is True
        assert self.service.get(created.id)    is None

    def test__delete__not_found(self):                        # Delete non-existent
        from sg_send_deploy_local_llm.schemas.types.Chat__Session_Id import Chat__Session_Id
        assert self.service.delete(Chat__Session_Id('00000000')) is False

    def test__list_sessions(self):                            # List returns summaries
        self._create_test_session()
        sessions = self.service.list_sessions()
        assert type(sessions) is list
        assert len(sessions)  >= 1
        first = sessions[0]
        assert 'id'            in first
        assert 'title'         in first
        assert 'model'         in first
        assert 'message_count' in first
```

from osbot_utils.type_safe.Type_Safe                                     import Type_Safe
from memory_fs.storage_fs.providers.Storage_FS__Memory                   import Storage_FS__Memory
from sg_send_deploy_local_llm.fast_api.Fast_API__Local_LLM              import Fast_API__Local_LLM

    fast_api__client: object                      = None     # TestClient

_test_objs = None                                            # singleton for test session

def setup__fast_api__local_llm__test_objs():
    global _test_objs
    if _test_objs:
        return _test_objs

        ollama_proxy    = ollama_proxy)

### Step 5.4: Write route tests

```python
# tests/unit/fast_api/routes/test_Routes__Sessions.py
from unittest                                                            import TestCase
from tests.unit.Fast_API__Test_Objs__Local_LLM                          import setup__fast_api__local_llm__test_objs

class test_Routes__Sessions(TestCase):

    @classmethod
    def setUpClass(cls):
        with setup__fast_api__local_llm__test_objs() as _:
            cls.client = _.fast_api__client

    def test__create_session(self):
        response = self.client.post('/api/sessions', json=dict(
            model    = 'gemma3:4b',
            title    = 'Test session',
            messages = [dict(role='user', content='hello')]))
        assert response.status_code == 200
        data = response.json()
        assert 'id'       in data
        assert data['model'] == 'gemma3:4b'

    def test__list_sessions(self):
        # create one first
        self.client.post('/api/sessions', json=dict(
            model='gemma3:4b', title='List test',
            messages=[dict(role='user', content='hi')]))
        response = self.client.get('/api/sessions')
        assert response.status_code == 200
        data = response.json()
        assert type(data)  is list
        assert len(data)   >= 1

    def test__get_session(self):
        create = self.client.post('/api/sessions', json=dict(
            model='gemma3:4b', title='Get test',
            messages=[dict(role='user', content='test')])).json()
        sid = create['id']
        response = self.client.get(f'/api/sessions/{sid}')
        assert response.status_code == 200
        assert response.json()['id'] == sid

    def test__get_session__not_found(self):
        response = self.client.get('/api/sessions/00000000')
        assert response.status_code == 404

    def test__delete_session(self):
        create = self.client.post('/api/sessions', json=dict(
            model='gemma3:4b', title='Delete test',
            messages=[dict(role='user', content='bye')])).json()
        sid = create['id']
        response = self.client.delete(f'/api/sessions/{sid}')
        assert response.status_code == 200
        assert response.json()['deleted'] is True
        # verify gone
        assert self.client.get(f'/api/sessions/{sid}').status_code == 404
```

**Gate:** All route tests pass with in-memory storage — no Docker, no Ollama needed.

## 6. Phase 5 — Streaming Chat Route

This is the novel pattern. Dev must determine which registration method works.

### Step 6.1: Try the standard pattern first

```python
def setup_routes(self):
    self.add_route_post(self.chat)
    return self
```

Test with:
```python
def test__chat__streaming(self):
    # This test verifies the route exists and accepts the right shape
    # Actual streaming requires Ollama — skip content verification
    response = self.client.post('/api/chat', json=dict(
        model    = 'gemma3:4b',
        messages = [dict(role='user', content='hi')],
        stream   = True))
    # If Ollama is not running, expect 502 or connection error — that's OK
    # The test verifies route registration and request parsing
    assert response.status_code in [200, 502, 503]
```

### Step 6.2: If standard fails, use direct registration

If `add_route_post` doesn't work with `StreamingResponse` or `async def`, switch to:

```python
def setup_routes(self):
    self.app().add_api_route(
        path     = f'/{self.tag}',
        endpoint = self._async_chat,
        methods  = ['POST'],
        tags     = [self.tag])
    return self

async def _async_chat(self, request: Request) -> StreamingResponse:
    body = await request.json()
    return StreamingResponse(
        self.ollama_proxy.stream_chat(body),
        media_type='application/x-ndjson')
```

**Document which approach worked.** This finding is valuable for the whole team.

## 8. Type_Safe Patterns to Follow (Quick Reference)

These are the specific patterns from the code review (`v0.5.7__sg_send_deploy__type_safe_code_review.md`) that apply to this module. **Do not repeat the mistakes documented there.**

| Pattern | Do This | Not This |
|---|---|---|
| **Class inheritance** | `class Service__Chat__Sessions(Type_Safe):` | `class Service__Chat__Sessions:` |
| **Dependencies** | `storage_fs : Storage_FS = None` as class attribute | `def __init__(self, storage_fs=None):` |
| **Method validation** | `@type_safe` on all public methods | No decorator |
| **Collections** | `List__Chat__Messages` (named subclass) | `messages: list` |
| **IDs** | `Chat__Session_Id(Obj_Id)` | `id: str` |
| **Timestamps** | `created_at : Timestamp_Now` | `datetime.now().isoformat()` |
| **JSON ops** | `json_dumps()`, `json_loads()` from `osbot_utils.utils.Json` | `import json; json.loads()` |
| **Enums** | `Enum__LLM__Role(str, Enum)` with `__str__` | `role: Literal["user", "assistant"]` |
| **File ops** | `Storage_FS.file__save()`, `file__json()` | `open(path, 'w')`, `json.dump()` |
| **Return not-found** | `return None` | `raise FileNotFoundError` |
| **No str() casts** | `session.id` directly | `str(session.id)` |

## 10. Success Criteria

The module is complete when:

- [ ] All schema tests pass (round-trip JSON serialisation, enum validation, collection typing)
- [ ] All service tests pass with `Storage_FS__Memory` (no Docker, no Ollama)
- [ ] All route tests pass via `TestClient` (no Docker, no Ollama)
- [ ] `docker compose up` serves the UI at `localhost:8080`
- [ ] `/api/models` returns the Ollama model list
- [ ] A chat message streams tokens in real time
- [ ] A session survives `docker compose down && docker compose up`
- [ ] Zero uses of raw `json` module, `datetime.now()`, plain `class Foo:`, or `def __init__` patterns
- [ ] `@type_safe` on every public service method
- [ ] The streaming registration pattern is documented (which approach worked)
